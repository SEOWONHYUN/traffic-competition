# 교통 공모전

서부정류장역·만촌역의 다음 365일 승하차를 예측하고, 991번 정평역 경유안의 거리·탄소배출량을 비교하는 분석입니다. 전처리, 모델 비교와 선정 근거, 오차 평가, 예측, 탄소 계산, 정책 적용 순서로 노트북에서 확인할 수 있습니다.

## 실행

1. **Code → Download ZIP**으로 내려받고 압축을 모두 풉니다.
2. Python 3.12 커널에서 `서부정류장_만촌역_수요예측.ipynb`를 엽니다.
3. `requirements.txt`의 패키지가 있는 환경에서 **Run All / 모두 실행**을 누릅니다.

패키지를 처음 설치하는 경우 노트북의 새 코드 셀에서 아래 명령을 실행한 뒤 커널을 다시 시작합니다.

```python
%pip install -r requirements.txt
```

입력 CSV 세 개가 포함되어 있습니다. 별도의 데이터 다운로드, API 키, 로그인이 필요하지 않습니다. 결과 CSV가 없어도 다시 계산됩니다.

## 데이터와 전처리

기관 자료에서 두 역을 추출해 일별로 집계한 **입력 CSV부터** 점검합니다. 기관의 전체 역 원천파일을 다시 다운로드·집계하는 코드는 포함하지 않습니다.

| 항목 | 범위 |
|---|---|
| 일별 실적 | 2021-01-01~2026-08-31, 두 역 각 2,069일, 총 4,138행 |
| 공휴일 | 2021~2027년 공휴일·발표일 139행 |
| 검증 예측 기준일 | 2022-12-31, 2023-08-31 |
| 과거 시험기간 | 2024-09-01~2026-08-31 |
| 향후 예측기간 | 2026-09-01~2027-08-31 |

열 이름·자료형을 정리하고 날짜를 정렬합니다. 역번호 대조, 날짜 중복·누락, 수치 결측·음수·비정수를 검사합니다. 해당 오류는 모두 0건이며, 임의 보간이나 고수요 일자 삭제는 하지 않았습니다. 각 예측 기준일까지 발표된 공휴일만 특징에 반영합니다.

## 모델과 결과

검증 비교로 정한 설정을 고정하고 기존 730일 CatBoost, 최근 8주 요일 중앙값, 최근 52주 반복과 비교합니다. 각 기준일 이후 365일을 한 번에 예측하며 미래 실적은 중간에 입력하지 않습니다.

| 역 | 적용 모델 | 시험 WAPE | 시험 MAE | 다음 365일 승하차 합계 |
|---|---|---:|---:|---:|
| 서부정류장역 | CatBoost RMSE, 최근 1,095일 | 4.33% | 663.71건/일 | 5,339,982건 |
| 만촌역 | CatBoost MAE·추세 회귀 50:50, 최근 1,095일 | 7.35% | 603.69건/일 | 3,276,639건 |

시험기간은 이전 모델 비교에 사용한 과거 구간입니다. 승하차는 고유 인원이 아닌 이용 건수입니다.

## 보행 접근성 검토와 AI 협업

- **서부정류장역:** 2026.6.30 공개 시설자료상 에스컬레이터는 0기입니다. 엘리베이터 3기 중 지상 출입용은 3번 출입구 옆 1기이며, 나머지 2기는 대합실·승강장 연결용입니다. 1·2번 방향에서 접근하는 휠체어 이용자의 지상 우회거리는 아직 측정하지 않았습니다.
- **고령인구의 공간 범위:** 2026년 8월 고령인구 비율 26.8~38.2%(대구 23.0%)는 서부정류장역 주변 생활권에 포함된 6개 행정동 기준입니다.
- **현장 관찰:** 팀이 제공한 「서부정류장역 불편함」의 글과 앞선 관찰을 참고했습니다. 다이소·세븐일레븐 사이 횡단부의 진입·우회전 차량 동선, 역 앞 무신호 횡단부와 공사 가림막, 정류장 옆 좁은 차로의 버스·승용차 혼재, 중앙 노점의 대기공간 점유, 1번 출구의 교행 문제가 기록되어 있습니다. 고장 시 안내를 찾기 어려운 점은 앞선 관찰이며, 운영기관에 지원체계가 전혀 없다는 뜻은 아닙니다. 시야 영향·파라솔 날림·충돌 가능성은 별도의 점검 대상입니다.
- **만촌역 출입구:** [2021.8.3 매일신문](https://www.imaeil.com/page/view/2021080315221807435)은 기존·신설 출입구의 방향 편중에 대한 만촌2동 주민 의견과 유동인구·교통영향평가에 따른 시의 설명을 함께 다뤘습니다. 당시의 문제 제기로 구분합니다.
- **같은 출발·도착점의 보행 기준:** 해링턴플레이스(만촌3동)에서 기존 만촌역 3번 출구까지 [카카오맵 도보 경로](https://kko.to/FFo-axi4tu)는 245m·약 4분·횡단보도 2곳입니다(2026.10.22 조회). 지도 경로이며 휠체어 경로의 실측값은 아닙니다. 같은 출발·도착점을 고정해 정비 전후를 평가하고 신설 출입구 이용안은 따로 비교합니다. 수성구청 방면 자동차 우회거리를 보행 접근성 개선효과로 사용하지 않습니다.
- **기존 안내의 보완:** [2022.4.7 보도](https://www.yeongnam.com/web/view.php?key=20220407010000890)는 공사 현장 우회 안내판 설치를 기록합니다. 청호로의 교차로 100m 전 방향표지는 [2025.10 로드뷰](https://kko.to/aIwuNuRUFZ)에서 확인했습니다. 기존 안내의 위치·내용을 점검하고, 부족한 목적지별 우회정보를 보완하는 제안입니다.
- **12개 보행 점검항목:** 단절, 우회, 경사, 평탄성, 미끄럼, 유효폭, 장애물, 횡단시설, 단차, 보차 혼용, 이동시설 연결, 야간 안전을 역별 근거와 연결했습니다. 교통약자법·시행규칙 별표 1과 보행안전법을 바탕으로 정리한 분석용 분류이며 법령이 정한 단일 12개 목록은 아닙니다. 경사·평탄성·미끄럼·단차와 야간 보행안전은 공식자료로 확인된 결함이 아닌 향후 현장 검증 대상입니다.

출입구 신설은 기존 사업입니다. 우리 팀의 제안은 주거지·정류장과 기존·신설 출입구 사이의 연속 보행경로와 횡단 대기공간을 보완하는 방향이며, 신설 출입구 자체의 효과와 구분합니다.
- **노선 운영:** 도심 비교구간에서 990·991번의 양방향 정류장 31개가 겹칩니다. 2026년 8월 동일 조건의 승차 집계는 120,900건·29,514건으로 약 4.10배 차이입니다. 일부 구간의 노선 중복과 이용규모 차이가 나타나므로 운행 공급의 적정성을 검토할 필요가 있습니다. 비효율성이나 대체 수용 능력을 단정하는 근거로 사용하지 않습니다. 운행 1회당 승차는 같은 기간의 승차 합계÷실제 완료 운행횟수로 계산해야 합니다. [대구 BIS 이용통계](https://businfo.daegu.go.kr:8095/dbms_web/content/businfo/usagestatus)의 2026.10.22 노선목록에는 두 노선과 실제 운행횟수가 없고, 2026.9 정류소 이용현황에도 노선별 분모가 없어 이 지표는 산출하지 않았습니다.

팀이 분석 대상·평가 기준을 정하고 ChatGPT와 자료 점검·전처리·모델 비교·탄소 계산 코드를 함께 작성·검토했습니다. 결과 해석·정책 제안·보고서 작성은 팀이 담당합니다. 보행환경 관찰은 예측 모델의 학습변수로 넣지 않았으며, 보행 개선과 991번 운행거리 감소의 효과는 따로 평가합니다.

## 991번 조정안과 탄소 계산

| 구분 | 경로 |
|---|---|
| 기존 | 임당역 → 경산시장 → 경산역 → 옥산네거리 → 사월역 |
| 제안 ②안 | 임당역 → 영대교 → 정평역 → 중산삼거리 → 사월역 |
| 유지 | 운행횟수와 사월역 이후 만촌역·도심 구간 |

계산은 **기존 왕복 1회를 제안 경로로 변경하는 경우**입니다. 기존 운행을 대체하고 추가 회송·대체수송이 늘지 않는 조건이다.

| 지표 | 기존 | 조정 | 감소 |
|---|---:|---:|---:|
| 왕복 거리 | 66.914km | 61.522km | 5.392km |
| CNG 참고 배출량 | 74.65kgCO₂eq | 68.63kgCO₂eq | 6.02kgCO₂eq·8.06% |

거리당 배출량은 `38.5 × (56030 + 92 × 28 + 3 × 265) ÷ 1,000,000 ÷ 2.05 = 1.115579756 kgCO₂eq/km`입니다. 연비 2.05km/m³의 m³는 Nm³와 같다고 가정했습니다. 원정밀도 입력으로 계산하고 마지막에 반올림합니다. 거리에는 이미 왕복이 반영돼 있으며 온난화지수도 한 번만 적용합니다.

이는 CNG 참고 조건의 변경 왕복 1회 추정이며 실제 차량의 연료 계측값이나 노선 전체 감축률은 아닙니다. 미경유 정류장 이용수요와 대체편을 확인한 뒤 시범 여부를 판단하는 제안입니다. 만촌역 보행 개선 효과와 경산 구간 거리 단축 효과는 구분합니다.
