# 교통 공모전

서부정류장역·만촌역의 일별 승차·하차 인원을 학습하고, 두 역의 다음 365일 수요를 예측하는 분석 코드입니다. 노트북에서 과거 예측 오차를 비교하고 표·그래프·결과 CSV를 생성합니다.

## 데이터와 평가 기간

| 구분 | 기간 |
|---|---|
| 입력 승하차 실적 | 2021-01-01~2026-08-31 |
| 검증 예측 기준일 | 2022-12-31, 2023-08-31 |
| 과거 시험기간 | 2024-09-01~2026-08-31 |
| 다음 365일 예측 | 2026-09-01~2027-08-31 |

입력 실적은 대구교통공사 일별 승하차 집계 자료를 두 역으로 정리한 것입니다. 역별로 2,069일씩 총 4,138행이 포함되어 있습니다. 공휴일 자료에는 발표일이 있으며, 각 예측 기준일까지 알려진 일정만 특징에 반영합니다.

## 적용 모델

| 역 | 모델 | 최종 학습기간 |
|---|---|---|
| 서부정류장역 | CatBoost, RMSE 손실 | 최근 1,095일 |
| 만촌역 | CatBoost와 추세 회귀의 50:50 결합 | 최근 1,095일 |

각 기준일 이후 365일을 한 번에 예측하며, 예측기간의 실제 승하차를 중간에 입력하지 않습니다. 최근 8주 요일 중앙값, 최근 52주 반복, 기존 CatBoost 설정과 MAE·RMSE·WAPE 등을 비교합니다.

## 결과 해석

- 승차·하차는 이용 건수이며 고유 이용자 수가 아닙니다.
- 예측은 역 전체의 수요를 대상으로 합니다. 출입구별·연령별 이용량이나 시설 개선의 효과를 추정한 값은 아닙니다.
- 축제, 돌발상황, 공사 및 노선 변경으로 발생하는 수요 변화는 충분히 반영하지 못할 수 있습니다.
- 과거 시험구간은 이전 모델 비교에도 사용했습니다. 기존 설정과의 개선 여부는 14일 블록 비교 결과와 함께 확인합니다.
- 포함된 예측 CSV는 실제 승하차 실적과 구분해야 합니다.
