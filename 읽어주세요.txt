서부정류장역·만촌역 수요예측과 991번 노선조정 분석

실행
1. ZIP을 모두 풉니다.
2. Python 3.12와 requirements.txt의 패키지가 있는 커널에서 노트북을 엽니다.
   패키지가 없으면 노트북 셀에서 %pip install -r requirements.txt 를 한 번 실행합니다.
3. 모두 실행합니다. 기존 결과 CSV가 없어도 입력 세 개로 다시 계산합니다.

분석 순서
입력 → 전처리·품질 점검 → 달력 특징 → 모델 비교 → 예측 오차 → 다음 365일 예측 → 탄소 계산 → 결론

필수 입력
data/일별승하차.csv: 두 역의 2021-01-01~2026-08-31 실적, 4,138행
data/공휴일.csv: 2021~2027년 공휴일·발표일, 139행
data/탄소계산_입력.csv: 991번 정평역 경유안의 거리와 CNG 참고 계산계수

적용 모델
서부정류장: CatBoost, 최근 1,095일, RMSE.
만촌: CatBoost와 추세 회귀의 50:50 평균, 최근 1,095일.
시험기간: 2024-09-01~2026-08-31. 이전 비교에 사용한 과거 구간입니다.
예측기간: 2026-09-01~2027-08-31.
승하차 합계는 이용 건수이며 고유 이용자 수가 아닙니다.

생성 결과
전처리_점검결과.csv / 모델비교_결과.csv
테스트데이터_예측결과.csv / 다음365일_예측결과.csv
탄소배출_계산결과.csv

탄소 계산
기존 991번의 왕복 1회를 정평역 경유 직통안으로 변경하는 시나리오입니다.
기존 운행을 대체하고 추가 회송·대체수송이 늘지 않는 조건이다.
공식 BIS 지도 경로선의 길이와 CNG 참고 연비 2.05km/m³를 사용합니다.
연비의 m³는 표준부피 Nm³와 같다고 놓았습니다. 실제 차량 연료 계측값은 아닙니다.
계수는 CO₂ 56030, CH₄ 92, N₂O 3 kg/TJ, 온난화지수 28·265, 순발열량 38.5MJ/Nm³입니다.
CH₄·N₂O의 온난화지수는 한 번만 적용하며, 거리 입력은 이미 왕복이므로 다시 2를 곱하지 않습니다.
참고 연비는 과거 공개 자료의 값이므로 실제 차량·운행 조건에 맞는 값이 확보되면 입력 CSV를 바꿔 다시 계산합니다.
